# Common Cents Course

## 1. Project Overview

Common Cents Course is a web-based financial literacy curriculum built for teens. Across 10 interactive sessions, learners explore money basics, banking, budgeting, saving, investing, security, and long-term planning.

## 2. Features

- 10 structured learning sessions
- Interactive worksheets
- Quizzes
- Parent dashboards
- Clean, easy-to-follow navigation
- Mobile-friendly layout
- Hosted via GitHub Pages

## 3. Curriculum Outline

1. What Money Is
2. Banking Basics
3. Budgeting & Cash Flow
4. Cards, Payments & Digital Money
5. Security & Fraud
6. Smart Spending & Value-Based Decisions
7. Short-Term Saving & Sinking Funds
8. Long-Term Goals & Retirement Thinking
9. Investing Basics
10. Vanguard & Long-Term Investing System

## 4. Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages for hosting

## 5. How to View the Site

After the repository is configured and deployed with GitHub Pages, open its published URL in a browser. Find the URL under the repository's **Settings → Pages**. GitHub Pages publishes the site from the configured branch and folder.

## 6. Local Development

Clone the repository, then open its `index.html` file in a browser:

```bash
git clone <repository-url>
cd common-cents-course
```

You can open `index.html` directly, or use a local development server if your browser or future site features require one.
